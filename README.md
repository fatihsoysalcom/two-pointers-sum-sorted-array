# Two Pointers Sum Sorted Array

This example demonstrates the Two Pointers pattern by solving the problem of finding a pair of numbers in a sorted array that sum up to a specific target value. Two pointers, one starting at the beginning and one at the end of the array, efficiently converge to find the solution or determine its absence. The approach significantly reduces time complexity compared to a brute-force method.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
